Featured

Flagship projects

Four projects with their own sites, docs and release builds — pick any and download it free.

Glassy IP Scanner

Fast, local-first network discovery for Windows, macOS and Linux. Scan IPs, ranges or CIDR blocks with ICMP/ARP/TCP probes and explore hostnames, vendors, open ports and a live network map.

TypeScript Electron MIT
GitHub Website Releases

StreamHarvest

Universal video downloader powered by yt-dlp. Paste a link, pick a quality, download — with playlists, subtitles, audio-only MP3 and up to 8 parallel downloads in the background.

TypeScript Electron yt-dlp
GitHub Website Releases

SC64 SD Card Builder

Guided wizard that prepares an SD card for the SummerCart64: format FAT32/exFAT, install the menu and metadata, 64DD IPLs, emulator cores and your whole ROM collection — verified byte-for-byte.

TypeScript Electron N64
GitHub Website Releases

Summer Breeze GUI

Cross-platform GUI for the SummerCart64 that wraps sc64deployer: deploy ROMs to the cart, back up saves, update the SC64 menu, sync the RTC and browse the SD card.

TypeScript Electron sc64deployer
